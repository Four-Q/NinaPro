- 每个文件包含 17 个数据字段；

因此，当前代码使用文件名和外部循环的 `subject_id` 识别受试者，并通过明确选择 `S*_E1_A1.mat` 确定 Exercise A，不依赖上述两个内部标量。

### 4.2 完整动作序列精简版

`data_prepare_full_sequence(simple).ipynb` 保留了以下主流程：

1. 查找项目根目录并设置路径；
2. 复用或准备 S1～S10 的 Exercise A MAT；
3. 使用 `emg`、`restimulus` 和 `rerepetition`；
4. 根据动作标签和 repetition 的变化找出连续动作序列；
5. 排除标签 0 的静息区段；
6. 将原始标签 1～12 映射为模型标签 0～11；
7. 按 repetition 划分训练集和测试集；
8. 使用 `X + offsets + lengths` 紧凑保存变长序列；
9. 重新加载 NPZ 并验证；
10. 提供 PyTorch 变长批次读取示例。

关键存储规则：

```python
sequence_i = X[offsets[i]:offsets[i + 1]]
```

磁盘中不进行截断或补零，组成训练批次时再按当前批次最长序列动态补齐。

### 4.3 滑动窗口精简版

`data_prepare_slide_window(simple).ipynb` 保留了以下主流程：

1. 复用或下载、提取 Exercise A；
2. 检查 MAT 必需字段和 EMG 有限性；
3. 使用有效性、动作标签和 repetition 找出连续区段；
4. 先按 repetition 选择 train/test，再在区段内部切窗；
5. 使用 200 ms 窗口和 100 ms 步长；
6. 将每个窗口从 `[时间, 通道]` 转置为 `[通道, 时间]`；
7. 保存 NPZ 和 metadata；
8. 重新加载并验证字段、形状、类型、标签和划分；
9. 提供 PyTorch 张量读取示例。

必须保持的数据处理顺序：

```text
连续动作区段
  ↓
按 repetition 划分 train/test
  ↓
分别生成滑动窗口
```

这样可以避免同一次动作中高度重叠的窗口同时进入训练集和测试集。

### 4.4 原始滑窗 Notebook 的兼容问题

`data_prepare_slide_window.ipynb` 的验证单元保存了以下错误：

```text
TypeError: 'type' object is not subscriptable
```

触发代码为：

```python
def validate_saved_dataset(
    path: Path,
    allowed_repetitions: tuple[int, ...],
) -> dict:
```

Notebook 的内核元数据为 Python 3.8，而 `tuple[int, ...]` 需要 Python 3.9 及以上。精简版按照当前项目约定移除了不必要的类型注解，因此没有该问题。
