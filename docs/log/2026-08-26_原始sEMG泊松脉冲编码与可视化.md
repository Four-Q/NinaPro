# 2026-08-26 原始 sEMG 泊松脉冲编码与可视化日志

## 1. 工作目标

本轮工作围绕 NinaPro DB5 Exercise A 滑动窗口数据，实现了不经过 Z-score 的原始 sEMG 泊松脉冲编码流程，并生成可直接供 SNN 使用的二值脉冲数据。

主要目标如下：

1. 区分已有神经形态电路编码与新增泊松编码，重命名相关 Notebook。
2. 直接读取 `ninapro_data/processed/exerciseA/slide_window` 中未经归一化的原始数据。
3. 生成“原始值加 128”和“正负极性分离”两种泊松二值脉冲表示。
4. 对同一个 200 ms 窗口分别生成 `T=40、80、120` 三种时间分辨率。
5. 保存训练集、测试集和完整编码元数据，并独立验证数据契约。
6. 从测试集抽取代表性样本，绘制原始 sEMG 与两种泊松编码的对比图。

本轮没有执行 SNN 训练或准确率网格搜索。最终发放率是依据原始数据分布、二值时间箱碰撞风险和目标脉冲密度确定的编码默认值，不代表经过分类准确率验证的全局最优超参数。

## 4. 泊松编码公共定义

新增 Notebook：

- `src/poisson_spike_encoding.ipynb`

所有目标 `T` 都表示同一个 200 ms 物理窗口，而不是不同的窗口时长。因此每个 SNN 时间箱宽度为：

\[
\Delta t=\frac{0.2}{T}\ \mathrm{s}
\]

对应关系如下：

| T | 时间箱宽度 | 原始 40 点到目标时间步的关系 |
|---:|---:|---|
| 40 | 5.000 ms | 每个原始采样对应 1 步 |
| 80 | 2.500 ms | 每个原始采样零阶保持 2 步 |
| 120 | 1.667 ms | 每个原始采样零阶保持 3 步 |

Notebook 使用零阶保持把 40 点原始序列映射到目标 `T`。对任意目标时间步，源索引定义为：

\[
i_{source}=\left\lfloor\frac{i_{target}\times40}{T}\right\rfloor
\]

若某个输入位置的瞬时泊松率为 \(\lambda\)，该时间箱中至少出现一次事件的概率为：

\[
p=1-\exp(-\lambda\Delta t)
\]

最终二值脉冲为：

\[
s\sim\operatorname{Bernoulli}(p),\qquad s\in\{0,1\}
\]

这里使用精确的泊松“至少一次事件”概率，没有使用仅在 \(\lambda\Delta t\ll1\) 时成立的近似 \(p\approx\lambda\Delta t\)。

## 5. 编码方案一：原始值加 128

该方案保持 16 个输入通道。首先将原始双极性值平移到非负范围：

\[
u=\operatorname{clip}(x+128,0,255)
\]

再线性映射为泊松率：

\[
\lambda=100\frac{u}{255}\ \mathrm{Hz}
\]

最终参数：

```python
OFFSET_128_MAX_RATE_HZ = 100.0
RAW_SHIFT = 128.0
AMPLITUDE_FULL_SCALE = 255.0
```

输出形状：

```text
(B, 16, T)
```

该方案的主要特征是原始 `x=0` 会映射到：

\[
100\times\frac{128}{255}\approx50.20\ \mathrm{Hz}
\]

因此即使原始值接近零，也会保持明显的基线发放。这是“加 128”映射本身的结果，而不是泊松采样错误。

## 6. 编码方案二：正负极性分离

为保留原始 sEMG 的正负信息，将每个原始通道拆分为正、负两个脉冲通道：

\[
x^+=\max(x,0),\qquad x^-=\max(-x,0)
\]

训练集原始绝对幅值分布如下：

| 分位点 | \(|x|\) |
|---:|---:|
| 90% | 20 |
| 95% | 30 |
| 97.5% | 43 |
| 99% | 62 |
| 99.5% | 78 |
| 99.9% | 109 |

若直接用完整 ADC 范围 128 作为幅值上限，大多数输入的泊松率会过低。最终采用固定参考幅值 64，接近训练集绝对幅值的第 99 百分位，并对归一化幅值应用 0.57 次幂，提升中低幅值的有效脉冲密度：

\[
a^+=
\left[
\operatorname{clip}\left(\frac{x^+}{64},0,1\right)
\right]^{0.57}
\]

\[
a^-=
\left[
\operatorname{clip}\left(\frac{x^-}{64},0,1\right)
\right]^{0.57}
\]

\[
\lambda^+=200a^+,\qquad\lambda^-=200a^-\ \mathrm{Hz}
\]

最终参数：

```python
POLARITY_SPLIT_MAX_RATE_HZ = 200.0
POLARITY_SPLIT_AMPLITUDE_REF = 64.0
POLARITY_SPLIT_AMPLITUDE_EXPONENT = 0.57
```

输出形状和通道顺序：

```text
(B, 32, T)
[ch0+, ..., ch15+, ch0-, ..., ch15-]
```

原始零值在正、负两组通道中都对应零发放率。幅值超过 64 的数据会达到最大率，训练集中 `|x| > 64` 的比例约为 0.91%。

最初使用线性映射、200 Hz 最大率时，正负分离训练集的密度约为 `5.19% / 2.80% / 1.92%`。加入 0.57 次幂后，密度提高到约两倍，同时没有把最大率提高到会使 `T=40` 严重饱和的约 480 Hz。

## 7. 随机性与复现

全局随机种子为：

```python
RANDOM_SEED = 42
```

不同编码、目标 `T` 和数据划分使用独立的 `numpy.random.SeedSequence`：

```text
[RANDOM_SEED, encoding_id, T, split_id]
```

没有使用 Python 的 `hash()` 生成种子，避免不同进程的哈希随机化影响结果。训练集和测试集、两种编码及三个 `T` 之间的随机序列相互独立。

Notebook 按 512 个窗口分块计算概率并采样，避免为 `(17839, 32, 120)` 一次性创建大型浮点概率张量。最终 `X` 使用 `uint8` 保存，且只包含 0 和 1。

随着 `T` 增大，平均密度下降是正常现象：同一个 200 ms 窗口被划分成更多二值时间箱。平均脉冲数/窗口更适合比较不同 `T` 的总体活动量。

平均脉冲数随 `T` 略有上升，是因为较粗时间箱会把同一时间箱内的多个泊松事件压缩成一个二值 1；提高时间分辨率后，这类事件更可能落入不同时间箱。

## 13. SNN 接入注意事项

两种数据已经是 `uint8` 二值脉冲。送入 PyTorch 模型前只需要转换为浮点类型和目标设备，不应再次执行 Z-score：

```python
x = x.to(device=device, dtype=torch.float32)
logits = model(x)
```

模型配置需要与通道数一致：

```text
offset_128     → input_channels=16
polarity_split → input_channels=32
```

当前 `NinaProSNN` 和 `DropoutPLIFSNN` 接受 `[B, C, T]`，并在模型内部转换成 SpikingJelly 多步模式使用的 `[T, B, C]`，因此外部不需要手动 `permute`。

当前 `create_data_pipeline()` 会自动应用逐通道 Z-score，不适合直接加载这些二值脉冲。后续训练时应使用不附加归一化 Transform 的数据集加载入口，或为泊松数据建立独立 DataLoader。

## 14. 结论与后续建议

本轮已经形成完整的原始 sEMG 泊松编码基线：

- 加 128 编码保留 16 通道，平均活动较密集，但零幅值存在约 50 Hz 基线发放。
- 正负分离编码扩展为 32 通道，原始零值保持静默，并显式保留信号极性。
- 0.57 次幂把正负分离编码密度提高约两倍，使其每窗口脉冲数量与加 128 编码处于相近量级。
- `T=40、80、120` 严格对应同一个 200 ms 窗口，可用于研究时间分辨率对分类性能和计算成本的影响。

建议后续使用完全相同的 SNN 拓扑和训练超参数，对以下变量进行受控实验：

1. `offset_128` 与 `polarity_split` 的分类准确率、宏平均 F1 和混淆矩阵。
2. `T=40、80、120` 的性能、训练耗时和推理成本。
3. 最大泊松率、幅值参考和幅值指数的小规模网格搜索。
4. 测试阶段固定编码与多次泊松采样平均 logits 的稳定性比较。
5. 输入层和隐藏层实际发放率，检查网络是否出现静默或饱和。
