## 2. V5设计动机

V4.1虽然让非零极性幅值直接进入1.8639～3.7278 V区间，但零幅值仍立即回到0 V。正负号变化时，两个极性分支会频繁在0 V与起振区间之间切换。当前每个原始采样值只保持5 ms，电路和突触状态可能在输入返回0 V后快速离开有效响应区域，导致最终脉冲仍然稀疏。

V5的思路是：

- 非零幅值映射保持不变；
- 零幅值不再回到0 V；
- 使用0.7562 V作为空闲基线；
- 让第一级NbOx输出在高阻态下接近突触响应阈值；
- 当非零输入到来时，电路从预偏置状态直接进入起振区间。

该方案试图在不修改电路参数和原始5 ms时序的情况下，提高有效输入产生脉冲的概率。

## 3. 0.7562 V的电路依据

第一级NbOx振荡神经元高阻态下的分压系数为：

\[
\alpha_H=
\frac{R_{in}}{R_{in}+R_{load}}
=
\frac{89213.44}{89213.44+10000}
\approx0.8992072042
\]

当输入电压为：

\[
V_{idle}=0.7562\text{ V}
\]

第一级输出节点的高阻态稳态电压约为：

\[
\alpha_HV_{idle}
\approx0.8992072042\times0.7562
\approx0.67998049\text{ V}
\]

Python突触模型中的响应阈值为：

\[
V_{th,syn}=0.67997329\text{ V}
\]

两者差值约为：

\[
0.67998049-0.67997329
\approx7.20\ \mu\text{V}
\]

因此，0.7562 V可以把第一级输出预偏置到突触开始响应的阈值附近。需要注意，该工作点与阈值非常接近，可能对参数精度、数值误差和器件偏差敏感，因此本轮同时使用LTspice和Python进行验证。

## 4. V5极性分离映射

对于原始第 \(c\) 个通道的样本 \(x_c\)，先进行极性分离：

\[
x_c^+=\max(x_c,0)
\]

\[
x_c^-=\max(-x_c,0)
\]

正、负幅值分别使用逐通道overall p99和p1绝对值归一化：

\[
z_c^+=
\operatorname{clip}
\left(
\frac{x_c^+}{p_{99,c}},
0,
1
\right)
\]

\[
z_c^-=
\operatorname{clip}
\left(
\frac{x_c^-}{|p_{1,c}|},
0,
1
\right)
\]

设：

\[
V_{idle}=0.7562\text{ V}
\]

\[
V_b=1.8639\text{ V}
\]

\[
V_{max}=3.7278\text{ V}
\]

V5最终映射为：

\[
\boxed{
V_c^\pm=
\begin{cases}
V_{idle},
&x_c^\pm=0\\[6pt]
V_b+(V_{max}-V_b)z_c^\pm,
&x_c^\pm>0
\end{cases}}
\]

主要对应关系为：

```text
极性幅值 = 0          -> 0.7562 V
极性幅值 > 0          -> 1.8639～3.7278 V
正幅值达到 p99,c      -> 正分支3.7278 V
负幅值达到 |p1,c|     -> 负分支3.7278 V
超过对应分位点         -> 限幅到3.7278 V
```

V5在零幅值和任意非零幅值之间仍然存在有意设计的电压跳变：

\[
0.7562\text{ V}
\longrightarrow
1.8639\text{ V以上}
\]

与V4.1相比，V5的唯一区别是零幅值对应电压：

| 项目 | V4.1 | V5 |
|---|---:|---:|
| 零极性幅值 | 0 V | 0.7562 V |
| 非零幅值起点 | 1.8639 V | 1.8639 V |
| 满量程电压 | 3.7278 V | 3.7278 V |
| 通道数 | 32 | 32 |
| 分位点端点 | p99与\(|p1|\) | p99与\(|p1|\) |

32通道顺序保持为：

```text
CH1+ ... CH16+, CH1- ... CH16-
```

## 11. 估算限制

上述外推不是完整编码结果，存在以下限制：

- 只随机抽取了3个窗口；
- 每个窗口只选择了6/16个原始通道；
- 三个窗口只覆盖3个动作和3名受试者；
- 分支和同一窗口内通道之间并非统计独立；
- 简单置信区间没有建模动作、subject、通道和窗口之间的聚类效应；
- V5的0.7562 V工作点非常接近突触阈值，长时间状态积累可能改变完整数据集统计；
- 当前只估算T=40二值密度；
- 如果同一5 ms时间箱出现多个脉冲，二值编码会将其合并为1；
- 当前样本中没有发生时间箱内脉冲合并，但完整数据集不保证始终如此。

需要特别区分两个“69个脉冲”：

- 原V4的69个脉冲来自完整训练集和测试集；
- V5的69个脉冲只来自本轮抽取的36条极性分支。

两者实验规模完全不同，不能直接把两个69理解为相同密度。

## 13. 当前结论

当前V5方法可以概括为：

> 继续使用逐通道p1/p99进行正负极性分离；零极性幅值不再映射到0 V，而是保持在0.7562 V，使第一级输出预偏置到突触响应阈值附近；非零幅值继续映射到1.8639～3.7278 V。每个原始通道扩展为正、负两个脉冲通道。

在随机抽取的3个窗口、36条极性分支上：

- LTspice和Python均产生69个脉冲；
- 36/36分支的脉冲数量完全一致；

- V5抽样二值密度约为4.79%；

V5显著提高了相对于V4.1的抽样脉冲密度，但当前4.79%的中心估计仍未达到10%～20%的目标，而且只基于3个窗口。下一步必须扩大分层样本或运行完整数据集编码，才能判断V5是否适合作为正式SNN输入映射。
