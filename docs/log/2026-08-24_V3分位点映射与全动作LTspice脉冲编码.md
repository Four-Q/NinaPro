# 2026-08-24 V3分位点映射与全动作LTspice脉冲编码日志

## 1. 工作概览

本轮工作在此前V1、V2输入映射实验的基础上，最终确定了适用于当前LTspice神经形态电路的V3输入映射方法

主要完成内容如下：

- 分析V2的RMS活动区映射缺点，重新采用保留原始正负号和波形顺序的分段线性映射；
- 根据第一级NbOx振荡神经元参数计算理论起振输入电压；
- 使用整个Exercise A数据集的每通道overall p1、p99作为V3映射端点；
- 将原始零值映射到理论起振电压1.8639 V；
- 将正、负半轴分别分配相同的1.8639 V电压宽度，因此最大电压为3.7278 V；
- 生成V3完整序列及5个窗口的验证输入，完成96项LTspice验证；
- 确认完整序列会出现突触长期累积，并决定在窗口级应用中通过时钟定时擦除消除窗口间状态积累；
- 对S1的12个动作各随机选择2个来自不同repetition的窗口；
- 生成24个窗口、384个通道PWL，并完成384项独立LTspice仿真；
- 从 `final_out` 提取精确脉冲时间戳；
- 生成1 ms和5 ms两种SNN分箱张量；
- 为12个动作分别绘制一张包含两个窗口、16个通道的脉冲栅格图；
- 完成输入、仿真、时间戳、SNN张量、汇总表和验证清单的一致性检查。

本轮没有修改 `System_with_TIA.asc`、NbOx模型或突触模型参数。V3与V1、V2的区别来自输入映射、窗口抽样和脉冲数据导出方式。

## 2. V3设计目标

V2使用5点因果RMS包络、Q95归一化、活动阈值和活动电压区间，虽然能够让活跃通道振荡，但存在以下问题：

1. RMS包络改变了原始sEMG波形形状；
2. 活动阈值会让低活动通道完全静默；
3. 绝对值/RMS处理丢失原始正负号；
4. 映射步骤较多，不利于解释输入与电路输出之间的关系。

V3因此采用以下设计原则：

- 不取绝对值；
- 不计算RMS；
- 不减去通道均值；
- 不使用活动区硬门控；
- 每个通道使用自己的p1、p99；
- p1到0以及0到p99分别采用线性映射；
- 负值始终映射到零值基准电压以下；
- 正值始终映射到零值基准电压以上；
- p1/p99以外的极端值进行限幅；
- 所有窗口保留NinaPro原始200 Hz采样时间尺度。

## 3. 零值电压与最大电压的确定

第一级NbOx模型主要参数为：

```text
VH     = 1.676 V
VL     = 1.127 V
Rin    = 89213.44 ohm
Rload  = 10000 ohm
Cparal = 1 uF
```

高阻态下输出节点相对于Vin的分压系数为：

\[
\alpha_H=\frac{R_{in}}{R_{in}+R_{load}}
=\frac{89213.44}{89213.44+10000}
\approx0.899207
\]

第一级神经元刚好能够到达高阈值 \(V_H\) 时，输入电压满足：

\[
\alpha_H V_{in}=V_H
\]

因此理论起振输入电压为：

\[
V_{osc}=\frac{V_H}{\alpha_H}
\approx1.863864\text{ V}
\]

V3将其取为：

\[
\boxed{V_0=1.8639\text{ V}}
\]

V3要求正、负半轴占用相同的输出电压宽度，因此：

- 负半轴使用0～1.8639 V；
- 正半轴使用1.8639～3.7278 V。

最大电压为：

\[
\boxed{V_{max}=2V_0=3.7278\text{ V}}
\]

需要注意，1.8639 V是理论振荡边界，而不是立即产生脉冲的电压。在当前RC参数下，接近该电压时首次起振较慢。但在最终方案中仍保留该锚点，用它表示原始数据正负号的电路分界。

## 4. 最终确定的V3分段线性映射

对第 \(c\) 个通道，令：

- 原始样本为 \(x_c\)；
- 该通道overall第1百分位数为 \(p_{1,c}<0\)；
- 该通道overall第99百分位数为 \(p_{99,c}>0\)；
- 零值电压为 \(V_0=1.8639\text{ V}\)。

最终V3公式为：

\[
V_{in,c}(x_c)=
\begin{cases}
0,
&x_c\le p_{1,c}\\[6pt]
V_0\dfrac{x_c-p_{1,c}}{-p_{1,c}},
&p_{1,c}<x_c<0\\[10pt]
V_0\left(1+\dfrac{x_c}{p_{99,c}}\right),
&0\le x_c<p_{99,c}\\[10pt]
2V_0,
&x_c\ge p_{99,c}
\end{cases}
\]

代入具体电压后：

\[
V_{in,c}(x_c)=
\begin{cases}
0,
&x_c\le p_{1,c}\\[4pt]
1.8639\dfrac{x_c-p_{1,c}}{-p_{1,c}},
&p_{1,c}<x_c<0\\[8pt]
1.8639\left(1+\dfrac{x_c}{p_{99,c}}\right),
&0\le x_c<p_{99,c}\\[8pt]
3.7278,
&x_c\ge p_{99,c}
\end{cases}
\]

三个核心锚点为：

```text
x <= p1,c  -> 0 V
x = 0      -> 1.8639 V
x >= p99,c -> 3.7278 V
```

该函数在p1、0和p99处连续。它不是整段只有一个斜率的单一仿射函数，而是以原始零值为连接点的连续分段线性函数。

### 4.1 正负信息如何保留

V3输入端满足：

\[
x_c<0\Rightarrow V_{in,c}<1.8639\text{ V}
\]

\[
x_c=0\Rightarrow V_{in,c}=1.8639\text{ V}
\]

\[
x_c>0\Rightarrow V_{in,c}>1.8639\text{ V}
\]

因此原始正负号在Vin中由相对于1.8639 V基准的位置表示。映射不会像V1/V2那样通过绝对值或RMS直接消除正负号。

### 4.2 相同电压宽度与斜率差异

正负半轴都使用1.8639 V电压宽度，但如果某通道满足 \(-p_1\ne p_{99}\)，两侧每个原始单位对应的电压增益仍不同：

\[
k_{-,c}=\frac{1.8639}{-p_{1,c}}
\]

\[
k_{+,c}=\frac{1.8639}{p_{99,c}}
\]

这是同时严格满足p1映射到0 V、零值映射到1.8639 V、p99映射到3.7278 V的必然结果。

## 6. PWL时间尺度与零阶保持

NinaPro DB5当前数据采样率为：

\[
f_s=200\text{ Hz}
\]

每个样本的实际时间为：

\[
T_s=\frac{1}{200}=5\text{ ms}
\]

PWL没有在相邻样本之间使用覆盖整个5 ms的线性斜坡，而是采用近似零阶保持：

- 每个映射电压保持4.999 ms；
- 在采样边界使用1 µs过渡到下一个样本；
- 40点窗口严格结束于0.200 s；
- 完整序列的总时长严格为样本数除以200。

这样既避免默认PWL线性插值造成额外斜坡，也保持了与NinaPro真实采样时间一致的电路激励。

384个通道窗口分别独立运行LTspice。每次仿真都从电路初始状态开始，等效于窗口开始前通过时钟完成突触擦除，不继承前一个窗口或动作的突触状态。

最终脉冲事件定义为：

\[
V(final\_out)\text{ 向上越过 }1.60\text{ V}
\]

上升沿时间不是直接取LTspice相邻采样点的离散时间，而是使用阈值两侧电压进行线性插值：

\[
t_{spike}=t_0+
\frac{1.60-V_0}{V_1-V_0}(t_1-t_0)
\]

其中 \((t_0,V_0)\) 位于阈值下方，\((t_1,V_1)\) 位于阈值上方。因此 `spike_events.csv` 和动作栅格图保存的是LTspice波形中的精确事件时刻，不属于1 ms或5 ms分箱结果。

- PWL总数为384；
- 缺失PWL数量为0；
- 每个PWL总时长严格为0.200 s；
- LTspice成功数为384/384；
- 脉冲CSV事件数为4850；

## 14. 当前结论与后续约定

最终确定的V3方法可以概括为：

> 使用整个数据集的逐通道p1/p99，把p1及以下映射到0 V，把原始零值映射到NbOx理论起振电压1.8639 V，把p99及以上映射到3.7278 V，p1到0和0到p99分别线性映射；按NinaPro 200 Hz时间尺度生成5 ms零阶保持PWL；窗口间通过时钟擦除突触状态；从 `final_out` 的1.60 V上升沿获得脉冲时间戳。

V3在当前24个随机窗口中实现了384/384通道均有脉冲输出，并形成了可直接用于SNN实验的1 ms、5 ms编码张量。

需要保留的实验限制包括：

- overall p1/p99使用了训练集和测试集的分布信息；
- 每通道独立归一化改变了通道之间的绝对增益比例；
- Vin中的正负关系不等价于 `final_out` 中存在正、负两类脉冲；
- 当前窗口数据依赖“窗口开始前完成突触擦除”的状态假设；
- 目前每个动作只有2个演示窗口，尚不足以直接完成具有统计意义的SNN训练比较；
- 后续扩展到完整训练集时，应保持相同映射统计量、擦除规则、上升沿阈值和时间分箱规则。
