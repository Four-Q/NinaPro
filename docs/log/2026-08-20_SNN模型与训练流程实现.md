## 3. SNN 设计决策

### 3.1 模型定位

当前模型只用于直接训练 SNN。未来的 ANN-to-SNN 转换使用独立模型，不要求当前模型同时承担转换目标。

这样可以避免混淆两种时间语义：

1. 当前模型把 40 个真实 EMG 采样点作为 40 个 SNN 时间步；
2. 传统 ANN-to-SNN 转换往往把静态 ANN 输入重复到额外的仿真时间维。

### 3.2 输入时间语义

数据管道输出：

~~~text
[B, 16, 40]
~~~

模型内部执行：

~~~text
[B, C, T] → [T, B, C]
~~~

因此每个 SNN 时间步接收当前时刻的 16 通道 EMG：

~~~text
T = 40
B = batch size
C = 16
~~~

输入是 Z-score 后的连续电流，不进行 Poisson、Rate 或 Delta 脉冲编码。该方案可以直接保留标准化信号中的正负数值。

### 3.3 网络结构

最终结构：

~~~text
输入 [B, 16, T]
  ↓ permute
[T, B, 16]
  ↓
Linear(16, 128)
  ↓
LIFNode
  ↓
Linear(128, 128)
  ↓
LIFNode
  ↓
Linear(128, 12)
  ↓
时间维平均
  ↓
logits [B, 12]
~~~

默认模型参数量：

~~~text
20,236
~~~

模型允许配置 input_channels、hidden_size、num_classes、tau、auto_reset 和 backend。

### 3.4 LIF 神经元配置

两个隐藏脉冲层均使用：

~~~text
LIFNode
tau = 2.0
decay_input = True
v_threshold = 1.0
v_reset = 0.0
surrogate_function = ATan()
detach_reset = True
step_mode = "m"
backend = "torch"
store_v_seq = False
~~~

tau 当前固定，不使用 ParametricLIFNode，因此膜时间常数不是可训练参数。

### 3.5 连续输出层

输出层不接 LIF。每个时间步产生线性分类输出，再对 40 个时间步取平均：

~~~python
logits = logits_sequence.mean(dim=0)
~~~

最终输出是无界的 [B, 12] logits，可以直接传入 CrossEntropyLoss。与平均放电率输出相比，连续读出层不会把分类分数限制在 [0, 1]。

### 4.1 输入检查

模型前向会检查：

- 输入必须是 torch.Tensor；
- 输入必须是三维 [B, C, T]；
- batch 维不能为空；
- 通道数必须与 input_channels 一致；
- 时间维不能为空；
- 输入必须是浮点张量。

时间长度没有硬编码为 40，因此模型也能处理其他长度的 [B, 16, T] 序列。

### 4.2 自动状态重置

每个滑动窗口批次彼此独立，因此默认在每次 forward 开始前重置两个 LIF 节点，同时提供 model.reset() 公开接口。

实现时发现一个 SpikingJelly 递归问题：如果普通 nn.Module 的 reset() 内部调用 functional.reset_net(self)，reset_net 会再次发现模型自身的 reset()，最终触发 RecursionError。

最终修复为直接重置实际的 MemoryModule：

~~~python
self.lif1.reset()
self.lif2.reset()
~~~

### 4.3 SNN 感知初始化

PyTorch Linear 默认初始化在当前网络中产生：

- 第一层 LIF 初始放电率约 0.5%；
- 第二层 LIF 初始放电率为 0；
- 分类器权重在第一步得到全零梯度。

为保持已经确认的网络结构和 LIF 参数不变，最终只调整初始权重尺度：

~~~text
第一层 Linear 权重：PyTorch 默认值 × 2
第二层 Linear 权重：PyTorch 默认值 × 4
分类器权重：保持 PyTorch 默认初始化
~~~

真实批次验证后，两层初始平均放电率约为：

~~~text
LIF 1：3.23%
LIF 2：0.40%
~~~

两层均保持稀疏，同时避免完全静默。

实现 ClassificationMeter 和 metrics_from_confusion_matrix，完全使用 PyTorch，不依赖 scikit-learn。

- 平均 CrossEntropy loss；
- overall accuracy；

- 每类 precision、recall 和 F1；
- 每类准确率；
- 混淆矩阵；
- 样本数量。

当前每类准确率定义为该类正确预测数除以该类真实样本数，等价于 recall。

### 5.3 checkpoint.py

检查点包含：

~~~text

model_state
optimizer_state
scheduler_state

normalization_state

~~~

保存使用同目录临时文件加 replace，降低训练中断时产生半写入检查点的风险。

PyTorch 2.6 以后完整训练状态加载需要显式 weights_only=False；实现同时保留旧版本不支持该参数时的 fallback。

### 5.4 reproducibility.py

seed_everything() 统一设置 Python random、NumPy、PyTorch CPU、PyTorch CUDA 和 cuDNN 状态。

默认：

~~~text
seed = 42
deterministic = False
~~~

默认不强制确定性 CUDA 算法，以避免未来 RTX 5090 环境出现不必要的性能损失；严格复现实验时可传 deterministic=True。

resolve_device() 自动优先选择 CUDA，否则使用 CPU。显式请求 CUDA 但不可用时会抛出清晰错误。

### 5.5 visualization.py

使用 Matplotlib 非交互式 Agg 后端，适合 Windows、Linux、Notebook 和无 GUI 服务器。

实现：

- UTF-8 JSON 保存；
- loss、accuracy、learning-rate 曲线；
- 混淆矩阵；
- 每类准确率柱状图。

训练曲线为数据点添加 marker，因此一个 epoch 的短跑也能看见数据点。

## 7. 每轮训练、测试与模型选择

每个 epoch 的流程：

~~~text
训练 epoch
  ↓
记录 train loss / accuracy
  ↓
完整运行 test epoch
  ↓
记录 test loss / accuracy
  ↓
根据 test accuracy 更新 best.pt
  ↓
更新 scheduler
  ↓
保存 last.pt 和 history.json
~~~

最佳模型规则：

1. test_accuracy 更高时更新；
2. 准确率相同时，test_loss 更低时更新。

训练结束后：

1. 保存最后一轮模型为 final.pt；
2. 从 best.pt 恢复模型；
3. 重新计算最佳模型的完整测试指标；
4. 保存 metrics.json；
5. 生成三张 PNG；
6. fit() 返回 history，调用方模型停留在最佳权重。

### 7.1 Test-selected checkpoint 说明

本项目明确要求每个 epoch 在测试集上评估，并使用测试准确率选择 best.pt。

因此：

~~~text
best.pt = test-selected checkpoint
~~~

测试集参与模型选择，在方法学上实际兼具验证集作用，best.pt 的测试准确率不能解释为完全无偏的最终泛化估计。

为避免误解：

- fit() 启动时输出提示；
- 检查点配置记录 selection_split = "test"；
- 检查点配置记录 test_selected_checkpoint = True；
- metrics.json 保留相同标记；
- Notebook 的开头和结果单元再次提醒。

如果未来需要严谨对外比较，应增加不参与模型选择的独立测试集，或采用固定超参数且只在训练结束后测试一次的协议。

~~~text

~~~

accuracy 在 JSON 中使用 0～1 小数，在终端和图像中显示为百分比。

## 10. 单批次过拟合诊断

实现 overfit_one_batch()，默认最多 500 步，达到 99% 准确率提前结束，并返回 step、loss 和 accuracy。

Notebook 中使用正式模型的深拷贝，因此诊断不会改变正式训练的初始权重。

最初计划直接取前 32 个样本，但真实数据按动作区段排列，前 32 个样本可能只属于一个类别。这种诊断即使达到 100% 也没有意义。

最终改为每类抽取 2 个样本：

~~~text
12 类 × 每类 2 个 = 24 个诊断样本
~~~

真实数据诊断结果：

~~~text
批次形状：[24, 16, 40]
各类样本数：[2, 2, 2, 2, 2, 2, 2, 2, 2, 2, 2, 2]
初始 loss：2.4863
初始 accuracy：8.33%
结束 loss：0.5718
结束 accuracy：100.00%
达到目标步数：367 / 500
~~~

该结果证明数据、模型、替代梯度、状态重置、损失和优化器形成了可学习链路。
