# 2026-08-27 V4极性分离映射方案日志

## 1. 工作概览

本轮在V3逐通道分位点映射的基础上，确定了新一版V4（`polarity_split`）输入映射方案。

V4的核心变化是将每个原始sEMG通道拆分为正、负两个幅值通道，使原来的16通道输入扩展为32通道。符号信息不再依赖电压相对于起振电压的位置，而是由正、负分支的通道身份表示；每个分支上的电压只表示该极性的幅值大小。

本轮完成的是V4数学定义和设计约定，尚未生成32通道PWL、修改LTspice仿真流程或导出新的脉冲编码结果。

## 2. V4设计目标

V3把原始负值映射到理论起振电压以下，把正值映射到理论起振电压以上。虽然这种方法在输入电压中保留了正负关系，但最终电路输出只有正向脉冲，负半波不能通过独立的脉冲通道直接表示。

V4采用极性分离，目标如下：

- 分别保留原始信号的正幅值和负幅值；
- 让正、负幅值都使用相同的非负电压范围；
- 用通道位置表示极性，用电压大小表示幅值；
- 保留原始样本顺序和NinaPro的200 Hz采样时间尺度；
- 继续使用逐通道鲁棒分位点抑制极端值的影响；
- 将零幅值明确映射为0 V，不添加起振电压偏置。

## 3. 正负极性分离

对于原始第 \(c\) 个通道的样本 \(x_c\)，定义：

\[
x_c^+=\max(x_c,0)
\]

\[
x_c^-=\max(-x_c,0)
\]

其中：

- \(x_c^+\)表示正幅值；
- \(x_c^-\)表示负值的绝对幅值；
- 两个分支均为非负值。

分离后仍满足：

\[
x_c=x_c^+-x_c^-
\]

并且任意时刻都有：

\[
x_c^+x_c^-=0
\]

因此，除零值外，同一个原始通道在同一采样时刻只有一个极性分支具有非零幅值。原始16通道由此扩展为：

\[
16\times2=32\text{通道}
\]

## 4. 分位点端点

V4当前沿用V3的逐通道overall分位点：

- 正通道使用该原始通道的第99百分位数 \(p_{99,c}>0\)；
- 负通道使用该原始通道第1百分位数的绝对值 \(|p_{1,c}|=-p_{1,c}>0\)。

定义两个分支的归一化幅值：

\[
z_c^+=\operatorname{clip}\left(
\frac{x_c^+}{p_{99,c}},0,1
\right)
\]

\[
z_c^-=\operatorname{clip}\left(
\frac{x_c^-}{|p_{1,c}|},0,1
\right)
\]

因此，超过对应分位点的极端幅值均被限幅为1。

## 5. 最终确定的V4电压映射

沿用V3的最大输入电压：

\[
V_0=1.8639\text{ V}
\]

\[
V_{max}=2V_0=3.7278\text{ V}
\]

需要注意，\(V_0\)在V4中只作为NbOx理论起振电压和确定最大电压的参考，不再作为原始零值对应的电压。

两个极性分支的电压映射为：

\[
\boxed{V_c^+=V_{max}z_c^+}
\]

\[
\boxed{V_c^-=V_{max}z_c^-}
\]

展开后，正通道为：

\[
V_c^+(x_c)=
\begin{cases}
0,
&x_c\le0\\[4pt]
V_{max}\dfrac{x_c}{p_{99,c}},
&0<x_c<p_{99,c}\\[8pt]
V_{max},
&x_c\ge p_{99,c}
\end{cases}
\]

负通道为：

\[
V_c^-(x_c)=
\begin{cases}
V_{max},
&x_c\le p_{1,c}\\[4pt]
V_{max}\dfrac{-x_c}{-p_{1,c}},
&p_{1,c}<x_c<0\\[8pt]
0,
&x_c\ge0
\end{cases}
\]

## 6. 核心锚点

V4的主要对应关系为：

```text
x = 0       -> 正通道0 V，负通道0 V
x >= p99,c  -> 正通道3.7278 V，负通道0 V
x <= p1,c   -> 正通道0 V，负通道3.7278 V
```

在分位点范围内：

- 正值只在正通道上进行线性幅值映射；
- 负值的绝对幅值只在负通道上进行线性幅值映射；
- 正、负通道使用相同的0～3.7278 V输出范围；
- 正负两侧仍允许使用不同的原始幅值增益，因为通常有 \(p_{99,c}\ne|p_{1,c}|\)。

两个分支的电压增益分别为：

\[
k_{+,c}=\frac{3.7278}{p_{99,c}}
\]

\[
k_{-,c}=\frac{3.7278}{|p_{1,c}|}
\]

## 7. 与V3的主要区别

| 项目 | V3 | V4 polarity_split |
|---|---|---|
| 输入通道数 | 16 | 32 |
| 符号表示方式 | 相对于1.8639 V的电压位置 | 正、负分支的通道身份 |
| 原始零值对应电压 | 1.8639 V | 两个分支均为0 V |
| 负值电压范围 | 0～1.8639 V | 负通道使用0～3.7278 V |
| 正值电压范围 | 1.8639～3.7278 V | 正通道使用0～3.7278 V |
| 限幅端点 | \(p_1\)和\(p_{99}\) | 正通道为\(p_{99}\)，负通道为\(|p_1|\) |

V4不再要求负值对应低于起振电压的输入。负幅值经过取绝对值后，在独立的负通道上使用与正幅值相同的正电压范围。

## 8. 电路起振含义

由于：

\[
V_{max}=2V_0
\]

任一极性分支达到理论起振电压 \(V_0\) 时，其归一化幅值为：

\[
z_{osc}=\frac{V_0}{V_{max}}=0.5
\]

也就是说，在静态理论分析下，分支幅值需要达到对应分位点幅值的约50%，映射电压才达到第一级NbOx神经元的理论起振边界。实际5 ms采样保持条件下的首次起振延迟和最终输出脉冲响应仍需通过LTspice验证。

## 9. 数据组织建议

V4数据在逻辑上可保存为：

\[
(N,2,16,T)
\]

其中极性维分别表示正、负分支。输入LTspice或SNN前可展平为：

\[
(N,32,T)
\]

具体的32通道排列顺序、文件命名规则和元数据字段尚未最终实现。后续应明确记录每个新通道对应的原始通道编号和极性，避免训练、仿真和可视化阶段发生通道错位。

## 10. 保留的V3时间规则

除通道拆分和幅值映射外，当前计划继续保留V3的时间处理方式：

- NinaPro原始采样率为200 Hz；
- 每个样本对应5 ms；
- PWL采用近似零阶保持；
- 每个映射电压保持4.999 ms；
- 在采样边界使用1 µs完成电压切换；
- 窗口级仿真开始前清除突触状态，避免窗口间长期累积。

这些规则需要在V4实现和仿真阶段再次进行一致性检查。

## 12. 当前结论

当前确定的V4方法可以概括为：

> 将每个原始sEMG通道拆分为正幅值和负幅值两个非负通道；正通道以逐通道p99作为满量程端点，负通道以逐通道p1绝对值作为满量程端点；两个分支均把零幅值映射到0 V，把对应分位点及以上映射到3.7278 V，中间进行线性映射并限幅。极性由32通道中的通道身份表示，电压只表示该极性的幅值。
