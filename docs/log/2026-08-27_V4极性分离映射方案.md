# 2026-08-27 V4基线电压极性分离映射方案日志

## 1. 工作概览

本轮在V3逐通道分位点映射的基础上，构建并修正了V4（`polarity_split`）输入映射方案。

V4的核心变化是将每个原始sEMG通道拆分为正、负两个幅值通道，使原来的16通道输入扩展为32通道。符号信息不再依赖电压相对于起振电压的位置，而是由正、负分支的通道身份表示；每个分支上的电压只表示该极性的幅值大小。

原V4将非零极性幅值从0 V线性映射到3.7278 V。实际编码发现该方案在全部训练集和测试集中仅产生69个脉冲，大量动作窗口和通道完全静默。针对该问题，当前V4改为：零幅值仍映射到0 V，非零幅值则以1.8639 V为基线，在1.8639～3.7278 V之间进行线性映射。

本轮已经获得原V4的稀疏编码结果，并确定了修正后的基线电压映射公式；新公式的完整数据生成和LTspice编码结果仍待重新运行与验证。

## 2. V4设计目标

V3把原始负值映射到理论起振电压以下，把正值映射到理论起振电压以上。虽然这种方法在输入电压中保留了正负关系，但最终电路输出只有正向脉冲，负半波不能通过独立的脉冲通道直接表示。

V4采用极性分离，目标如下：

- 分别保留原始信号的正幅值和负幅值；
- 让正、负幅值都使用相同的非负电压范围；
- 用通道位置表示极性，用电压大小表示幅值；
- 保留原始样本顺序和NinaPro的200 Hz采样时间尺度；
- 继续使用逐通道鲁棒分位点抑制极端值的影响；
- 将零幅值明确映射为0 V，使空闲极性通道保持静默；
- 对非零幅值加入起振基线电压，提高5 ms输入保持期间产生脉冲的概率。

## 3. 正负极性分离

对于原始第 \(c\) 个通道的样本 \(x_c\)，定义：

\[
x_c^+=\max(x_c,0)
\]

\[
x_c^-=\max(-x_c,0)
\]

其中：

- \(x_c^+\)表示正幅值；
- \(x_c^-\)表示负值的绝对幅值；
- 两个分支均为非负值。

分离后仍满足：

\[
x_c=x_c^+-x_c^-
\]

并且任意时刻都有：

\[
x_c^+x_c^-=0
\]

因此，除零值外，同一个原始通道在同一采样时刻只有一个极性分支具有非零幅值。原始16通道由此扩展为：

\[
16\times2=32\text{通道}
\]

## 4. 分位点端点

V4当前沿用V3的逐通道overall分位点：

- 正通道使用该原始通道的第99百分位数 \(p_{99,c}>0\)；
- 负通道使用该原始通道第1百分位数的绝对值 \(|p_{1,c}|=-p_{1,c}>0\)。

定义两个分支的归一化幅值：

\[
z_c^+=\operatorname{clip}\left(
\frac{x_c^+}{p_{99,c}},0,1
\right)
\]

\[
z_c^-=\operatorname{clip}\left(
\frac{x_c^-}{|p_{1,c}|},0,1
\right)
\]

因此，超过对应分位点的极端幅值均被限幅为1。

## 5. 原V4电压映射及问题

原V4使用以下直接线性映射：

\[
V_{old,c}^+=V_{max}z_c^+
\]

\[
V_{old,c}^-=V_{max}z_c^-
\]

其中：

\[
V_0=1.8639\text{ V}
\]

\[
V_{max}=2V_0=3.7278\text{ V}
\]

因为原映射从0 V开始，达到理论起振电压所需的归一化幅值为：

\[
z_{osc}=\frac{V_0}{V_{max}}=0.5
\]

大部分sEMG样本幅值较小，因此映射电压长期低于或接近1.8639 V。同时，每个采样值只保持5 ms，接近理论起振边界的输入通常难以在有限保持时间内驱动电路产生脉冲。

原V4实际编码结果为：

- 全部训练集和测试集合计仅产生69个脉冲；
- 大量动作窗口完全没有输出脉冲；
- 大量通道处于完全静默状态；
- 有效sEMG变化难以传递到后续SNN。

因此，原V4的0～3.7278 V直接线性映射不再作为当前方案。

## 6. 当前V4基线电压映射

当前方案使用：

\[
V_b=1.8639\text{ V}
\]

\[
V_{max}=3.7278\text{ V}
\]

对于正、负两个极性分支，最终电压统一定义为：

\[
\boxed{
V_c^\pm=
\begin{cases}
0,
&x_c^\pm=0\\[4pt]
V_b+(V_{max}-V_b)z_c^\pm,
&x_c^\pm>0
\end{cases}}
\]

展开后，正极性通道为：

\[
V_c^+(x_c)=
\begin{cases}
0,
&x_c\le0\\[4pt]
V_b+(V_{max}-V_b)\dfrac{x_c}{p_{99,c}},
&0<x_c<p_{99,c}\\[8pt]
V_{max},
&x_c\ge p_{99,c}
\end{cases}
\]

负极性通道为：

\[
V_c^-(x_c)=
\begin{cases}
V_{max},
&x_c\le p_{1,c}\\[4pt]
V_b+(V_{max}-V_b)\dfrac{-x_c}{-p_{1,c}},
&p_{1,c}<x_c<0\\[8pt]
0,
&x_c\ge0
\end{cases}
\]

## 7. 核心锚点与映射性质

V4的主要对应关系为：

```text
x = 0       -> 正通道0 V，负通道0 V
x > 0       -> 正通道从1.8639 V起映射，负通道0 V
x < 0       -> 正通道0 V，负通道从1.8639 V起映射
x >= p99,c  -> 正通道3.7278 V，负通道0 V
x <= p1,c   -> 正通道0 V，负通道3.7278 V
```

在分位点范围内：

- 正值只在正通道上进行线性幅值映射；
- 负值的绝对幅值只在负通道上进行线性幅值映射；
- 零幅值对应0 V，非零幅值使用1.8639～3.7278 V有效映射区间；
- 正负两侧仍允许使用不同的原始幅值增益，因为通常有 \(p_{99,c}\ne|p_{1,c}|\)。

两个分支的电压增益分别为：

\[
k_{+,c}=\frac{3.7278-1.8639}{p_{99,c}}
\]

\[
k_{-,c}=\frac{3.7278-1.8639}{|p_{1,c}|}
\]

该映射在零点存在有意设计的电压跳变：幅值严格为0时输出0 V，任意非零幅值则进入以1.8639 V为基线的有效区间。这一设计用连续性换取空闲分支静默和非零输入的可起振性。

## 8. 三种映射的主要区别

| 项目 | V3 | 原V4 | 当前V4基线映射 |
|---|---|---|---|
| 输入通道数 | 16 | 32 | 32 |
| 符号表示方式 | 相对于1.8639 V的电压位置 | 正、负通道身份 | 正、负通道身份 |
| 原始零值对应电压 | 1.8639 V | 两个分支均为0 V | 两个分支均为0 V |
| 非零幅值起始电压 | 由V3分段公式决定 | 从0 V连续增加 | 从1.8639 V起增加 |
| 有效映射上限 | 3.7278 V | 3.7278 V | 3.7278 V |
| 负值表示 | 低于1.8639 V | 负通道非负电压 | 负通道基线以上电压 |
| 限幅端点 | \(p_1\)和\(p_{99}\) | 正侧\(p_{99}\)，负侧\(|p_1|\) | 正侧\(p_{99}\)，负侧\(|p_1|\) |

当前V4保留了原V4的极性分离、32通道结构、分位点归一化和零值静默，只修改非零幅值对应的电压区间。

## 9. 电路起振含义

当前映射中，任意非零幅值满足：

\[
V_c^\pm>V_b=V_0
\]

因此，非零输入会直接进入理论起振边界以上，而不再需要先跨越原V4中前50%的归一化幅值区间。幅值继续通过1.8639～3.7278 V之间的电压变化影响电路起振延迟和脉冲响应。

该修改预计能够显著提高脉冲密度，但不意味着每个非零的5 ms样本都必然产生脉冲。实际输出仍受RC动态、前序状态、输入持续时间和后级突触状态影响，需要重新运行完整训练集与测试集编码进行验证。

## 10. 数据组织建议

V4数据在逻辑上可保存为：

\[
(N,2,16,T)
\]

其中极性维分别表示正、负分支。输入LTspice或SNN前可展平为：

\[
(N,32,T)
\]

具体的32通道排列顺序、文件命名规则和元数据字段尚未最终实现。后续应明确记录每个新通道对应的原始通道编号和极性，避免训练、仿真和可视化阶段发生通道错位。

## 11. 保留的V3时间规则

除通道拆分和幅值映射外，当前计划继续保留V3的时间处理方式：

- NinaPro原始采样率为200 Hz；
- 每个样本对应5 ms；
- PWL采用近似零阶保持；
- 每个映射电压保持4.999 ms；
- 在采样边界使用1 µs完成电压切换；
- 窗口级仿真开始前清除突触状态，避免窗口间长期累积。

这些规则需要在V4实现和仿真阶段再次进行一致性检查。

## 13. 当前结论

当前确定的V4方法可以概括为：

> 将每个原始sEMG通道拆分为正幅值和负幅值两个非负通道；正通道以逐通道p99作为满量程端点，负通道以逐通道p1绝对值作为满量程端点。幅值严格为0时输出0 V；幅值非零时，以1.8639 V为基线，在1.8639～3.7278 V之间线性映射，并在对应分位点处限幅。极性由32通道中的通道身份表示，电压只表示该极性的幅值。

该修正针对原V4全部训练集和测试集合计仅69个脉冲的问题，目标是在保持零值静默的同时，减少有效sEMG信息在LTspice脉冲编码阶段的丢失。
