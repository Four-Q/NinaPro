# NinaPro DB5 数据集说明

## 1. 数据集特点

NinaPro DB5 使用两只消费级 Myo 臂环采集 16 通道、200 Hz 的前臂表面肌电（sEMG）信号。它的数据规模相对适中，尤其适合 SNN、边缘计算和神经形态硬件实验。



### 1.1 数据集单位

> **NinaPro记录的是肌电电压经过采集系统处理后的数字采样值，而不是人体产生的电流数据**。其中DB5尤其不是带有“伏特”单位的原始模拟电压。
>
> **经过商业采集前端，不是真正裸露电极上的原始电压。**
>
> 数值范围约为−128～127；
>
> 单位是“arbitrary Myo unit”，即Myo设备内部的任意数字单位；
>
> 所以DB5中的一个数值，例如`emg=64`，**不能解释为64 V、64 mV或64 μA**，也不能直接反算为人体皮肤上的准确电压。

其完整链路可以理解为：

```
肌肉活动
   ↓
皮肤表面差分电压
   ↓
Myo电极与模拟前端
   ↓
放大、滤波
   ↓
8-bit ADC，200 Hz
   ↓
数字值−128～127
   ↓
NinaPro DB5文件
```



### 1.2 能否用于In-sensor Computing＋SNN？

**可以，而且非常适合先做算法和器件应用演示，但不能只依靠DB5证明完整的真实传感器性能。**



**硬件链路：**

```
NinaPro DB5数字数据
        ↓
归一化和标定
        ↓
DAC／任意波形发生器
        ↓
模拟电压
        ↓
神经形态器件系统
        ↓
脉冲或模拟特征
        ↓
SNN分类网络
```



## 2. 双 Myo 臂环配置

每只 Myo 臂环包含 8 个单差分干式电极，两只臂环合计形成 16 个 sEMG 通道：

- 通道 1～8：来自靠近肘部的上方 Myo；
- 通道 9～16：来自靠近手腕的下方 Myo；
- 下方 Myo 相对上方旋转约 22.5°，用于填补上方电极之间的空间间隙。

Myo 的 sEMG 采样率为 200 Hz。

DB5 中 `emg` 的原始幅值不是以 µV 或 mV 表示的物理电压，而是 Myo 臂环输出的 8 位有符号原始数值：

- 数值范围：−128～127；
- 单位：Myo arbitrary units（任意单位，a.u.）。

由于官方没有提供转换为实际电压的标定系数，因此绘图时应标注为 `Raw amplitude (a.u.)`，不能标注为 µV 或 mV。

该采集配置具有以下优点：

- 数据量和计算量较小；
- 设备价格较低，佩戴方便；
- 不需要剃毛或涂抹导电胶；
- 适合实时识别和低功耗硬件实现。

## 3. Exercise A 动作类别

DB5 的 52 个动作分为三个 Exercise。其中，Exercise A 包含 12 个基本手指动作：

DB5 有 10 名受试者，每名受试者对应 1 个 Exercise A 文件，因此共有 10 个 Exercise A 文件。文件数量表示受试者数量，并不表示动作类别数量；每个文件都包含完整的 12 类动作，而且每类动作重复 6 次。整体数据结构可以表示为：

```text
10 名受试者 × 12 类动作 × 每类 6 次重复
```

| 局部编号 | 动作 |
| --- | --- |
| 1～2 | 食指屈曲、伸展 |
| 3～4 | 中指屈曲、伸展 |
| 5～6 | 无名指屈曲、伸展 |
| 7～8 | 小指屈曲、伸展 |
| 9～10 | 拇指内收、外展 |
| 11～12 | 拇指屈曲、伸展 |

## 4. 推荐的数据集划分

DB5 中最常见的跨重复划分方式为：

- 训练集：重复 1、3、4、6；
- 测试集：重复 2、5。

必须先根据 `repetition` 或 `rerepetition` 划分训练集和测试集，再分别执行滑动窗口切分。这样可以避免同一次动作的相邻或重叠窗口同时进入训练集和测试集，从而防止数据泄漏。

## 5. 面向 SNN 的数据处理流程

推荐采用以下处理流程：

```text
读取 .mat
→ 选择 emg
→ 使用 restimulus 和 rerepetition
→ 按重复次数划分训练集和测试集
→ 移除或单独处理动作过渡区
→ 使用训练集统计量进行归一化
→ 使用 200 ms 滑动窗口切分
→ 将 sEMG 编码为脉冲
→ 输入 SNN
```



### 5.1 DB5信号如何映射到器件输入



不能把−128～127直接当成电压。应根据器件安全输入范围进行标定。简单映射可以写成：

\[ x_{\mathrm{norm}}(t)=\frac{x(t)-\mu_{\mathrm{train}}}{s_{\mathrm{train}}} \]

再进行限幅：

\[ \hat{x}(t)=\operatorname{clip}(x_{\mathrm{norm}}(t),-1,1) \]

若器件使用双极性电压：

\[ V_{\mathrm{in}}(t)=V_{\mathrm{cm}}+V_{\mathrm{scale}}\hat{x}(t) \]

其中：

- \(V_{\mathrm{cm}}\)：器件工作点；
- \(V_{\mathrm{scale}}\)：允许的输入摆幅；
- 所有均值、标准差和限幅阈值只能用训练集估计，避免测试数据泄漏。

如果器件只能接收正电压，可以采用：

\[ V_{\mathrm{in}}(t)=V_{\min} +\frac{\hat{x}(t)+1}{2}(V_{\max}-V_{\min}) \]

也可以把正、负肌电分别映射到两条输入通路：

\[ x^+(t)=\max(x(t),0),\qquad x^-(t)=\max(-x(t),0) \]

这对忆阻器阵列、双通道突触和SNN脉冲编码通常更容易实现。



### 5.2 实验路线

1. **软件验证**
   使用DB5 Exercise A的12类基本动作，完成预处理、脉冲编码和SNN分类。训练使用第1、3、4、6次重复，测试使用第2、5次重复。
2. **器件硬件在环验证**
   将DB5通过DAC回放到器件，测量器件输出并重新送入SNN。比较理想数字信号、器件仿真信号和实际器件输出三种情况。
3. **真实传感器端到端验证**
   使用自己的肌电传感器＋神经形态器件采集少量真实受试者数据，尽量采用与DB5相同的动作和重复协议。用DB5预训练，再用自采数据校准或微调。

最终论文可以同时报告：

- DB5上的标准分类结果；
- 器件回放下的分类结果；
- 自研传感器真实采集结果；
- 端到端功耗、延迟和能耗；
- 器件漂移、噪声、通道失配和电极位移鲁棒性。
