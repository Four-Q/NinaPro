# V3 p1/p99 对称分段线性映射仿真验证

## 验证范围

- 数据：NinaPro DB5 Exercise A，S01，标签0，重复1。
- 完整序列：787点，3.935 s。
- 随机窗口：5个，每个40点、0.200 s，起点为1063、1323、1463、1543、1743。
- 通道：16个；完整序列16项，窗口80项，共96项LTspice仿真。
- 统计量：整个数据集（训练集+测试集）的每通道 overall p1/p99。
- PWL：200 Hz，每个样本以1 µs过渡近似零阶保持5 ms。

映射锚点为：

```text
x <= p1_c  -> 0 V
x = 0      -> 1.8639 V
x >= p99_c -> 3.7278 V
```

p1到0以及0到p99之间分别采用连续线性映射。

## 输入映射检查

在选中的完整序列、16个通道上平均：

| 指标 | 结果 |
|---|---:|
| 原始负值比例 | 56.67% |
| 原始零值比例 | 11.37% |
| 原始正值比例 | 31.96% |
| p1低端限幅比例 | 0.25% |
| p99高端限幅比例 | 0.32% |
| 1.8639～1.90 V比例 | 12.47% |
| 1.8639～2.05 V比例 | 28.87% |

完整序列中有5个通道实际到达0 V，5个通道实际到达3.7278 V。整体限幅比例较低，说明本次样本的大部分原始幅值顺序得到保留。但接近三成输入落在1.8639～2.05 V的慢起振区域，零点附近存在明显的动态死区风险。

## 独立窗口仿真

每个窗口均从电路初始状态独立启动。80个通道窗口的 `Vout` 和 `final_out` 全部发生振荡。

| 窗口 | 起点 | final_out总上升沿 | 通道平均频率/Hz | 最低/最高频率/Hz |
|---:|---:|---:|---:|---:|
| 1 | 1063 | 253 | 79.06 | 60～100 |
| 2 | 1323 | 211 | 65.94 | 30～90 |
| 3 | 1463 | 211 | 65.94 | 20～100 |
| 4 | 1543 | 243 | 75.94 | 50～100 |
| 5 | 1743 | 259 | 80.94 | 35～105 |

全部窗口合计检测到1177个 `final_out` 上升沿，单通道窗口平均频率为73.56 Hz，范围为20～105 Hz。

独立窗口频率明显低于完整序列，不是输入映射不同，而是每个窗口重新初始化了振荡器和突触状态。若后续用于连续数据编码，应优先对完整序列连续仿真，再从输出中切窗口，避免人为重置状态。

## 验证结论

V3完成了以下目标：

- Vin保持原始数据的正负分界和每侧的线性顺序。
- 16个通道均能驱动第一级振荡，不再出现V2中低活动通道被直接静默的问题。
- p1/p99限幅在该样本中的总体占比较低。

但本次验证也发现两个主要问题：

1. 完整序列下 `final_out` 很快进入持续高频区，时间变化在整段图上被压缩成密集振荡。
2. 通道汇总的第一级频率和最终频率呈负相关，表明最终输出主要受突触累积状态控制，不能直接假定它单调保留Vin幅值或第一级脉冲率。

因此，V3作为输入映射能够成功起振，但当前参数下尚不能直接认定为适合SNN编码的最终方案。下一步应检查突触状态与 `VDRIVE`，并对完整序列按短时间窗统计 `final_out` 的瞬时频率，确认其是否仍保留动作的时间变化。
